# Test Automation Assignment 3 - Employee Object

This assignment demonstrates an example employee object in **XML**, **YAML**, and **JSON** formats.

## Employee Object Model

| Field       | Data Type | Description                       |
|------------ |---------- |-----------------------------------|
| firstName   | string    | Employee's first name             |
| lastName    | string    | Employee's last name              |
| age         | number    | Employee's age                    |
| department  | string    | Department the employee works in  |
| jobTitle    | string    | Employee's job title              |
| isCatLover  | boolean   | Whether the employee likes cats   |

## Employee Information
- First Name: Mehtap  
- Last Name: Parkinson  
- Age: 30  
- Department: Engineering  
- Job Title: Associate Software Developer  
- isCatLover: true  

---
## XML Format
```xml
<Employee>
    <firstName>Mehtap</firstName>
    <lastName>Parkinson</lastName>
    <age>30</age>
    <department>Engineering</department>
    <jobTitle>Software Developer</jobTitle>
    <isCatLover>true</isCatLover>
</Employee>
```
## YAML Format
```yaml
firstName: Mehtap
lastName: Parkinson
age: 30
department: Engineering
jobTitle: Software Developer
isCatLover: true
```
## JSON Format
```json

  "firstName": "Mehtap",

  "department": "Engineering",
  "jobTitle": "Software Developer",
```
